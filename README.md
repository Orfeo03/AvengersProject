A Marvel-inspired website I built using React, JavaScript, GSAP, and CSS.

I wanted to create something more interactive than a normal website, so I added animations, character profiles, movie information, and a few features that users can interact with.

Features:
Animated homepage with scroll effects
Marvel character profiles
Search and filter heroes by team
Add and remove favorite characters
Explore Marvel movies and upcoming releases
Countdown for Avengers: Doomsday
Responsive design for desktop and mobile

Built With:
React
JavaScript
Vite
GSAP and ScrollTrigger
CSS
Lucide React
